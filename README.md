# [Dental Clinic Name] - Modern Dental Practice Website

A responsive, elegant, and calming dental healthcare website built with modern HTML5, CSS3, and JavaScript.

## Features

- **Soothing, Non-Neon Aesthetic**: Tailored with deep slate navy, gentle medical teal, and warm porcelain tones.
- **Mobile-First & Fully Responsive**: Slide-out mobile navigation drawer, touch-friendly tap targets, and a sticky mobile quick-action bottom bar.
- **Interactive Before & After Smile Gallery**: Interactive comparison slider with case study tabs for whitening, veneers, and clear aligners.
- **4-Step Appointment Booking Wizard**: Multi-step booking workflow with instant confirmation code generation.
- **Transparent Pricing & Insurance Estimator**: Real-time calculator reflecting PPO insurance tiers and membership discounts.
- **FAQ Accordion & Emergency Dental Notice**: Immediate care guidance and patient information.

## Deployment

### 1-Click Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fujjwal81011-pixel%2Fdentist)

Click the button above or follow these simple steps to deploy:
1. Log in to [Vercel](https://vercel.com).
2. Go to [https://vercel.com/new](https://vercel.com/new).
3. Under **Import Git Repository**, select **`ujjwal81011-pixel/dentist`**.
4. Click **Deploy**. Vercel will automatically build and publish your website to a live `*.vercel.app` URL with continuous updates whenever you push changes!
